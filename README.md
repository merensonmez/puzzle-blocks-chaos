## 🚀 About the Project

**Puzzle Blocks: Chaos** is a mobile block puzzle game focused on simple mechanics, quick gameplay, and a casual user experience.

The game redefines the classic block puzzle experience with modern visuals, smooth animations, and multiple game modes.

Players place blocks on a 10×10 board, clear lines, and aim for the highest score. The gameplay is easy to learn but hard to master.

Users can play Puzzle Blocks: Chaos to:

- Enjoy quick block puzzle gameplay
- Play short mobile game sessions
- Clear lines on a 10×10 board
- Challenge their focus and strategy
- Compete for high scores
- Experience a simple and accessible casual game
